# LECTIO 0.2 — завершение интеграции

Ядро 0.2 уже написано (`text.ts`, `types.ts`, `analysis.functions.ts`, `ai.ts`, `demo.ts`). Эти файлы остаются как есть — доделываю только интеграцию UI, хранилища и проверку сборки.

## Что фактически ещё не подключено

- `AnalysisPanel.tsx` использует старую модель: `details`-секции, нет разделения word/phrase, нет истории follow-up, `saveVocab` вызывается без `occurrences`/`analysis`/`author`.
- `reader.$bookId.tsx` передаёт только `selection/sentence/context` — без prev/next предложения, абзаца, автора; в настройках нет sepia и `markStudied`.
- `ReaderView.tsx` не подсвечивает изученные слова и не отдаёт расширенный контекст.
- `storage.ts` пишет `VocabEntry` без `lemma`/`occurrences` — новые типы не удовлетворены, миграции нет.
- `vocabulary.tsx` не показывает встречи.
- Маршрута истории (`/history`) нет.
- `__root.tsx` — без `ThemeSync`, `Toaster`, шрифтов; заголовок всё ещё «Lovable App».
- `styles.css` — sepia-темы и стиля отметки изученных слов нет.

## План работ

### 1. Карточка анализа
Переписать `AnalysisPanel.tsx`:
- расширенный вход: prev/next предложение, абзац, автор, kind;
- для слова — компактная шапка (контекстный перевод → лемма → произношение → морфология → роль в предложении), ниже collapsible-секции: Значение, Грамматика, Почему именно это слово, Синонимы, Этимология, Словообразование, Коллокации, Контекст, Примеры;
- для фрагмента — Перевод, Буквально, Что здесь происходит, Синтаксис, Ключевые элементы, Почему автор написал так, Контекст; word-only поля скрыты;
- пустые поля не рендерятся; показывается `confidence` и метка AI/демо;
- «Спросить» — input, loading, список сообщений, передача `analysisDigest` и истории в уже готовый `requestFollowUp`;
- сохранение в словарь передаёт лемму, перевод, контекст, книгу, автора и весь `analysis`.

### 2. Ридер и контекст
- `ReaderView` собирает контекст через `sentenceWindow`, `paragraphs`, `contextAt` из `text.ts` (клик по слову и выделение фрагмента);
- подсветка изученных слов через `tokenize`/`normalizeForm` — только тонкая подчёркивающая линия, без фона, без ломания выделения;
- `reader.$bookId.tsx` добавляет в запрос автора, язык, книгу, UI-язык; в настройки — переключатель темы light/sepia/dark и тумблер «Отмечать изученные».

### 3. Sepia и стили
Добавить в `styles.css` класс темы `sepia` (тёплая бумага, приглушённый графитовый текст) и стиль `.lectio-studied`.

### 4. Личный словарь
- `storage.ts`: ключ записи — лемма + язык; повторное сохранение добавляет `occurrence`, а не дубликат; функция миграции читает старые записи по тем же ключам (`lectio.vocab.v1`) и достраивает `lemma`/`occurrences`. Ключи хранилища не меняются, данные не удаляются;
- `vocabulary.tsx`: количество встреч, раскрытие истории контекстов (предложение, книга, автор, дата), заметка пользователя.

### 5. История исследований
Новый маршрут `/history`: список записей (фрагмент, слово/фраза, книга, автор, дата, краткий контекстный смысл), по клику — сохранённый разбор; ссылка из библиотеки.

### 6. Root
`__root.tsx`: `<ThemeSync />`, `<Toaster />` (sonner), шрифты через `<link>` в head, метаданные LECTIO вместо шаблонных. Проверить отсутствие дублирующих провайдеров.

### 7. Сборка и проверка
- прогнать typecheck/build, устранить все ошибки;
- e2e-прогон в Playwright: открыть книгу, импортировать TXT, слово → анализ → разделы → follow-up, фрагмент → phrase-анализ, сохранение и повторное сохранение той же леммы (вторая встреча), словарь, история, sepia, markStudied, сохранение позиции чтения, mobile viewport;
- проверить, что существующие localStorage-данные читаются после миграции.

В конце — короткий отчёт: сделано, изменённые файлы, миграции, проверенные сценарии, известные проблемы.
